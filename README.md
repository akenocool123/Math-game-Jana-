# Parallelogram Interactive Activity

Files:
- `index.html`
- `assets/parallelogram.png`

For GitHub Pages:
1. Upload the entire contents of this folder to a GitHub repository.
2. Keep the `assets` folder next to `index.html`.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your branch (usually `main`) and `/ (root)`.
6. Save.

The image path is relative (`assets/parallelogram.png`), so it will work on GitHub Pages.
